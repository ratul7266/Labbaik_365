# ✅ Labbaik 365 – Task Manager

**Labbaik 365** হলো একটি **simple, clean, web-based task manager**, যেখানে তুমি তোমার daily tasks, deadlines, এবং priorities efficiently manage করতে পারবে।  

এই project টার goal হলো **productivity increase করা**, life organize রাখা, এবং users কে **distraction-free environment** provide করা।  

---

## 🚀 Why this project exists

আজকের fast-paced lifestyle-এ আমরা অনেক সময় **important tasks ভুলে যাই বা delay করি**।  
**Labbaik 365** তৈরি করা হয়েছে সেই problem solve করার জন্য।  

- Daily tasks track করা সহজ  
- Priority & deadlines clear রাখা যায়  
- Productivity improve হয়  

---

## ✨ Features

-  **Add / Edit / Delete Tasks** – দ্রুত এবং সহজভাবে task manage করা যায়  
-  **Mark as Completed** – done tasks track করা যায়  
-  **Organized Layout** – tasks category বা priority অনুযায়ী arrange করা  
-  **Responsive Design** – mobile এবং desktop দুই-ই smooth  
-  **Lightweight & Fast** – unnecessary load ছাড়া clean performance  

---

## 🎯 Purpose

- Daily life organized রাখা  
- Time management improve করা  
- Stress কমানো by visualizing tasks  
- Productivity boost করা
